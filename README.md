# 云梦AI代充商城 / Yunmeng AI Top-up Mall

Digital goods e-commerce mall inspired by [yunmeng.fit](https://yunmeng.fit/).

Built with full SDLC process.

## Current Status

See real-time progress: [docs/progress.md](docs/progress.md)

## Tech Stack (planned)

- Next.js 15 + TypeScript + Tailwind
- Prisma (SQLite for dev, PostgreSQL for production)
- Docker Compose for cloud host deployment
- One-click backup / restore / deploy scripts

## Development

```bash
npm install
npm run dev
```
